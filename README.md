# História e Importância do JavaScript

## História do JavaScript
O JavaScript foi criado em **1995** por *Brendan Eich* enquanto trabalhava na Netscape.  
Ele foi desenvolvido em apenas **10 dias** para permitir que páginas da web ficassem interativas.

Inicialmente chamado de **Mocha**, depois **LiveScript**, e finalmente **JavaScript**, ele se tornou um padrão e foi adotado por todos os navegadores.

Com o tempo, evoluiu através do padrão **ECMAScript (ES)**, que define a linguagem oficialmente.

## Importância do JavaScript
Hoje o JavaScript é uma das linguagens mais importantes do mundo porque:

- Roda em **todos os navegadores**.
- Permite criar **interatividade**, animações e interfaces modernas.
- Funciona no **back-end** (com Node.js).
- Cria **aplicativos mobile** (React Native).
- Cria **jogos**, **extensões de navegador**, **APIs** e até controla **hardware**.

É a única linguagem capaz de rodar **nativamente no navegador**.  
Por isso, praticamente **todo site moderno usa JavaScript**.
